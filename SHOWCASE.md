## CLI Usage Examples

### Basic Usage
```bash
$ keyarch
# Opens interactive TUI

$ keyarch --help
# Shows all available commands and flags
```

### Quick Tests
```bash
$ keyarch --mode quick
# 15-second test (default)

$ keyarch --mode quick --duration 30
# 30-second test

$ keyarch --mode quick --duration 60
# 60-second test
```

### Word Tests
```bash
$ keyarch --mode words
# 25 words (default)

$ keyarch --mode words --words 50
# 50 words

$ keyarch --mode words --words 100
# 100 words
```

### Themed Tests
```bash
$ keyarch --theme nord
# Start with Nord theme

$ keyarch --theme dracula --mode quick
# Quick test with Dracula theme

$ keyarch --theme gruvbox-dark --mode quote
# Quote mode with Gruvbox theme
```

### Direct Modes
```bash
$ keyarch --mode quote
# Random inspirational quote

$ keyarch --mode code
# Random code snippet

$ keyarch --mode words --words 75
# Exactly 75 words
```

## Keyboard Shortcuts Reference

### All Screens
```
↑ or k      Move up
↓ or j      Move down
Enter       Select/Confirm
Space       Alternative select (some screens)
ESC         Go back / Cancel
q           Quit (from menus)
Ctrl+C      Force quit (anywhere)
```

### During Test
```
Type        Any letter or number
Space       Space character
Backspace   Delete last character
ESC         Exit to menu
Ctrl+C      Force quit
```

### Theme Selector
```
↑/↓         Preview themes in real-time
Enter       Save and apply theme
ESC         Cancel and return
```

## File Size & Performance

**Binary Size:**
- Unoptimized: ~15 MB
- Optimized: ~8 MB
- UPX compressed: ~3 MB

**Runtime Performance:**
- Startup time: < 100ms
- Input latency: < 10ms
- Memory usage: ~10-20 MB
- CPU usage: < 5% (idle), ~15% (active)

**Database Growth:**
- ~1 KB per test result
- ~100 tests = ~100 KB
- ~1000 tests = ~1 MB
